# Font licenses

## Silkscreen

Used as ShopProfit's pixel display typeface through Google Fonts. The family
provides Regular and Bold weights and is listed under the SIL Open Font
License 1.1.

- Copyright: 2001 The Silkscreen Project Authors
- Google Fonts source and metadata: https://github.com/google/fonts/tree/main/ofl/silkscreen
- License text: https://raw.githubusercontent.com/google/fonts/main/ofl/silkscreen/OFL.txt

The site loads the font stylesheet from Google Fonts and falls back to the
system monospace stack if it is unavailable. Functional copy remains in the
system sans-serif stack.
